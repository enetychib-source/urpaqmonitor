# Urpaq Monitor — Гидрологический мониторинг Казахстана и система мониторинга уровня воды Arduino

## Быстрый запуск проекта
Для корректной работы **Web Serial API** (подключение Arduino по USB) сайт должен быть открыт в браузере **Google Chrome** или **Microsoft Edge** через `http://localhost` (или `https://`).

1. Распакуйте архив и откройте терминал в папке `UrpaqMonitor_2910`.
2. Запустите локальный HTTP-сервер:
   ```bash
   python -m http.server 8000
   ```
3. Откройте в Google Chrome или Microsoft Edge адрес:
   `http://localhost:8000`

## Подключение Arduino по USB
1. Загрузите скетч из папки `arduino_sensor/arduino_sensor.ino` в плату Arduino Uno / Nano (скорость `9600` бод).
2. **Важно:** закройте «Монитор порта» (Serial Monitor) в Arduino IDE, чтобы COM-порт не был занят.
3. На странице Urpaq Monitor нажмите кнопку **«🔌 Подключить Arduino»** и выберите ваш COM-порт во всплывающем окне браузера.
4. При поступлении строк формата:
   ```json
   {"station_id":"dam_01","parameter":"water_level","value":42,"unit":"%"}
   ```
   панель мониторинга, история показаний и графики начнут обновляться автоматически.

## Проверка порогов и тревоги (с Arduino и без неё)
- **Норма:** `0–49%`
- **Предупреждение:** `50–79%` (однократный предупреждающий звуковой сигнал при переходе)
- **Тревога:** `80–100%` (пульсирующая визуальная тревога и двухтональная звуковая сирена с интервалом повтора 4 с)
- Кнопка **«🔔 Звук: Вкл / 🔇 Звук: Выкл»** отключает только звук, сохраняя визуальную индикацию тревоги.
- При отсутствии физической платы раскройте блок **«🧪 Тестовый режим и проверка сценариев»** внутри панели Arduino и протестируйте кнопки `49%`, `50%`, `79%`, `80%`, `100%` и `Проверить потерю данных (5 с)`. Тестовые данные изолированы и не записываются в реальную историю Arduino в `localStorage`.
