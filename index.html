🚨 Датчик уровня воды Arduino (USB Serial)

Подключите Arduino по USB (9600 бод) для мониторинга уровня воды в реальном времени.

Режим: USB Serial ● Отключён
⚠ Ограничение окружения для Web Serial API

Для работы с USB-портом откройте сайт в браузере Google Chrome или Microsoft Edge через локальный сервер (например: python -m http.server 8000 и перейдите на http://localhost:8000).

🧪 Тестовый режим и проверка сценариев (без записи в реальную историю Arduino)

Тестовые измерения позволяют проверить пороги (49%, 50%, 79%, 80%, 100%), звук, потерю сигнала (>5 с) и графики. Они помечаются как демонстрационные и не смешиваются с реальной историей USB Arduino в localStorage.
